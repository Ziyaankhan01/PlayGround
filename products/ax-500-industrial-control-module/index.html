AX-500 Industrial Control Module

The AX-500 is a rugged IP67 distributed control node that shortens wiring runs and speeds up commissioning. Dual-protocol networking, hot-swap I/O slices and an open function-block library make it ideal for new machines and brownfield retrofits.
